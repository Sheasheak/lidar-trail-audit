Trail Line Editor

Correct the trail line against LiDAR & aerial imagery

How to use

Drag the white vertices to move the line onto the real track. Click a mid-point handle to add a vertex; right-click a vertex to delete. Use the layer control (top-right of map) to switch aerial / hillshade / slope.

DEM overlay opacity

Hillshade/slope reveal the graded bench under tree canopy where aerial can't see it.
