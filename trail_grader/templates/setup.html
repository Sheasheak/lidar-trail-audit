NZ MTB Trail Grader — Setup

First-time setup. You need to download the Canterbury-Christchurch LiDAR 1m DTM from LINZ and point the app at it.

Step 1 — Download the DTM Go to LINZ Layer 123193, download the full dataset as AAIGrid format, and extract the zip somewhere on your computer.
Step 2 — Enter the folder path below Paste the path to the folder containing the .asc tile files.
This is the folder that contains files like DEM_BX24_2025_1000_2414.asc
